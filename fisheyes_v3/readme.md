# 鱼眼运动检测 — V3：利用标定参数改进光流质量

## 一、项目背景

鱼眼相机具有超大视场角，广泛应用于自动驾驶环视、机器人视觉感知、智能交通、全景监控等领域。但鱼眼镜头的非线性畸变导致传统基于透视图像的运动分析方法性能下降。

本项目在 V2 基础上，探索四条利用相机标定参数的技术路线：

- **Route B（去畸变域处理）**：将鱼眼图像映射到透视域后执行运动检测
- **Hybrid Flow** ⭐：融合透视域和鱼眼域的 Farneback 光流幅值，V3 最优
- **Residual Flow（残差光流）**：利用地面投影分离背景自运动
- **Angular Flow（角位移）**：将像素位移转为物理角位移，消除畸变尺度差异

## 四、V3 技术路线与实验结果

### 4.1 Route B — 去畸变域检测

**思路**：利用 radial_poly 标定将鱼眼图像映射至透视域，在透视域运行 V12，再将 mask 反投影回鱼眼域评估。

**结果**：

| fov_scale | Mean F1 | vs V12 | 分析 |
|-----------|---------|--------|------|
| 1.0 | 0.1687 | -0.032 | 边缘目标被压缩/裁剪 |
| 0.5 | 0.1792 | -0.022 | 边缘拉伸恶化 Farneback |

**结论**：透视图中心区域 Farneback 质量确实优于鱼眼域（小目标帧提升 +0.03~0.07），但边缘透视拉伸导致 Farneback 窗口假设失效。纯 Route B 无法同时兼顾中心和边缘。

### 4.2 Residual Flow — 残差光流

**思路**：利用外参（相机高度 0.66m）计算地面平面投影，估计路面区域的自运动光流，从原始光流中减去背景分量。

**结果**：Mean F1 = 0.2001，与 V12 持平（-0.0007）。

**结论**：Farneback 光流的路面中值仅 0.2~1.0 px/frame，而噪声主体（2~5 px）来自结构性伪影而非自运动，减去微小背景分量对 magnitude 几乎无影响。

### 4.3 ⭐ Hybrid Flow — 混合光流幅值（当前最优）

**思路**：

```
鱼眼域 Farneback → mag_fish ─────────────╮
                                           ├→ w(r)·mag_p + (1-w)·mag_f → V12 Pipeline
透视域 Farneback → mag_persp → 标量反投 ─╯
                     ↑                    ↑
              fov_scale=1.0         w(r): 中心→1.0, 边缘→0.0
```

- 中心区域（r<0.35）：完全使用透视域 magnitude，Farneback 质量更优
- 边缘区域（r>0.65）：完全使用鱼眼域 magnitude，避免透视拉伸
- 过渡带（0.35<r<0.65）：余弦平滑

**结果（20帧）**：

| 指标 | V1 | V12 | **HF (最终)** | Δ vs V12 |
|------|-----|------|------|------|
| **Mean F1** | 0.1546 | 0.2008 | **0.2050** | **+0.0042** |
| Precision | 0.1033 | 0.1574 | 0.1602 | +0.0028 |
| Recall | 0.8432 | 0.3716 | 0.3794 | +0.0078 |
| Frame wins | 4 | 6 | **10** | — |

**关键单帧**：00005 (+0.035), 00037 (+0.035), 00053 (+0.014), 00006 (+0.009)

### 4.4 Angular Flow — 角位移

**思路**：利用 radial_poly 标定将每个像素的 flow 向量转为物理角位移：

```
ang_mag(u,v) = arccos(ray(u,v) · ray(u+fx, v+fy))
```

角位移在中心和边缘有统一的物理含义（rad/frame），消除畸变引起的尺度差异。

**结果（20帧）**：

| 指标 | V12 | HF | AB |
|------|-----|-----|-----|
| Mean F1 | 0.2008 | **0.2040** | 0.1978 |

**结论**：方向正确（00000 +0.015, 00053 +0.030），但像素域阈值直接线性缩放到角位移域不够精确，需单独搜索参数。架构已就绪。

### 4.5 四条路线汇总（20帧）

| 路线 | Mean F1 | vs V12 | 状态 |
|------|---------|--------|------|
| V12 (V2 基线) | 0.2008 | — | 基准 |
| Route B | 0.1792 | -0.022 | ❌ 边缘问题无法解决 |
| Residual Flow | 0.2001 | -0.001 | ≈ 持平，无效 |
| **Hybrid Flow** | **0.2050** | **+0.0042** | ✅ V3 20帧最优 |
| Angular Flow | 0.1978 | -0.003 | ⏳ 方向正确，阈值待调 |

> ⚠️ **注意**：以上为 20 帧手工子集结果。全量 130 帧评估见[第八节](#八全量130帧评估与v3优化)。

## 五、处理全流程（Hybrid Flow）

```
输入: prev_f, curr_f (鱼眼灰度, 1280×966)
               │
  ┌────────────┴────────────┐
  │  鱼眼域 Farneback        │  透视域 Farneback
  │  flow_f = FB(p_f, c_f)  │  p_p = undistort(p_f)
  │  mag_f = ‖flow_f‖       │  c_p = undistort(c_f)
  │                         │  flow_p = FB(p_p, c_p)
  │                         │  mag_p = ‖flow_p‖
  │                         │  mag_pr = reproject(mag_p)
  └────────────┬────────────┘
               │
       mag = w(r)·mag_pr + (1-w)·mag_f
       w(r): 中心≈1.0, 边缘≈0.0 (余弦过渡)
               │
  ┌────────────┴──────────────────────────┐
  │           V12 Pipeline                 │
  │                                        │
  │  diff = |c_f - p_f|, p95 = P95(diff)  │
  │                                        │
  │  p95>120 or <20? ──→ V1 fallback      │
  │  else: 5-bin 自适应参数                │
  │    seed = diff > seed_th (空间过滤)    │
  │    cand = mag_ratio > ratio_th         │
  │    expand = cand (距seed ≤ expand_d)   │
  │    mask = seed | expand                │
  │                                        │
  │  CCA 三级过滤:                         │
  │    L1: area < 100px → 删除            │
  │    P0-2: 信号验证 (diff/mag vs 全局)   │
  │    P0-3: 种子面积比 < 3% → 删除        │
  │    L2+L3: 形状/密度检查                │
  │                                        │
  │  morph open + close (7×7)              │
  └────────────────────────────────────────┘
               │
        输出: mask (0/255 二值)
```

### 全流程关键参数

| 阶段 | 参数 | 值 | 说明 |
|------|------|-----|------|
| 混合 | w(r) 过渡带 | r∈[0.4, 0.7] | 余弦平滑 |
| 去畸变 | fov_scale | 1.0 | 透视图视场 |
| 候选 | ratio_thresh | 1.3~2.2 | p95_diff 5档自适应 |
| 候选 | flow_thresh | 1.5~2.0 | p95>70 时启用 |
| 种子 | seed_thresh | 14~22 | p95 分档 |
| 种子 | min_neighbors | 3~4 | 7×7 邻域像素数 |
| 扩张 | expand_dist | 4~12 | p95 分档 |
| CCA | min_area | 100px | 最小组件面积 |
| CCA | sig_diff_ratio | 1.5 | mean_diff/global_diff |
| CCA | sig_mag_ratio | 1.3 | mean_mag/global_mag |
| CCA | seed_area_ratio | 0.03 | 组件内种子占比 |
| 形态学 | morph_ksize | 7 | 开闭运算核大小 |

| 指标 | 20帧 | 130帧 | |

| FP总像素 | — | **13,102,089** | 每帧平均10万假阳性 |

**核心问题**：V12 的 mag_ratio 候选区生成，在 130 帧中产生了海量假阳性。Precision 仅 5%，即每 20 个"检测到运动"的像素中 19 个是假阳性。

### 8.4 最终 V2 改进（Test 7 保留）

三项核心改进，FP 减少 81 万（-6.2%），F1 提升 3.2%：

**a) mag × diff 联合 saliency + 小窗口**
```
saliency = (mag+0.1) × (diff+0.1)
saliency_mean = GaussianBlur(saliency, 21×21, σ=7)  // 原 41×41
candidate = saliency/saliency_mean > threshold
```
- 同时要求光流和帧差都高于局部背景，噪声难以在两个通道同时高
- 窗口从 41→21 减少均匀区域（天空/路面）的过度放大

**b) 方向一致性（所有主 pipeline bin 启用）**
- 扩张像素的 flow 方向必须与邻近种子一致（偏差 < 45°）
- V12 在大部分 bin 禁用了此检查

**c) 约束膨胀替代距离变换**
- 从种子出发做迭代膨胀，只沿连通候选路径扩展
- 不跨越候选区断裂处（距离变换会跨越 ≤ expand_dist 的间隙）

## 十、后续优化迭代思路

当前 F1=0.0617 的瓶颈在于：剩余 FP 在现有信号维度（mag、diff、方向、CCA）下与真实运动不可区分。以下按可行性排序，列出可能的突破方向。

### 10.1 新信号维度（优先尝试）

**a) 边缘相关性**
- 核心观察：真实运动物体的 flow 与图像边缘位置重叠（运动物体有轮廓）；Farneback 纹理噪声均匀分布
- 实现：`edge_corr = mag × gradient_magnitude`，要求光流高的位置同时有图像梯度
- 预期收益：抑制建筑物立面、路面等均匀纹理区的 Farneback 伪影

**b) 多尺度 saliency 共识**
- 当前只用 21×21 单窗口计算局部均值，噪声在不同尺度下表现不一致
- 实现：同时计算 11×11、21×21、41×41 三个尺度的 saliency_ratio，取最小值或要求多数尺度假阳性
- 预期收益：真实运动在所有尺度都显著，噪声只在某个尺度凸显

**c) Flow 散度/旋度分析**
- 真实运动区域 flow 具有空间一致性（相邻像素方向相似），噪声方向随机
- 实现：计算 `div = ∂fx/∂x + ∂fy/∂y` 和 `curl = ∂fy/∂x - ∂fx/∂y`，真实运动散度/旋度低
- 当前方向一致性检查已是简化版，但仅检查与种子的方向差，未利用邻域连续性

### 10.2 方法改进

**a) 超像素级分类**
- 当前是逐像素 → 种子扩张 → CCA 的管线，中间没有语义级聚合
- 实现：SLIC 超像素（~500 个/帧），每个超像素计算平均 mag、平均 diff、flow 方向方差、边缘密度，用阈值或简单分类器判定
- 优势：天然保证空间连续性和形状规整，不会有椒盐噪声或细长伪影

**b) 分水岭（Watershed）分割**
- 当前种子扩张用距离变换或迭代膨胀，本质是无差别的几何扩张
- 实现：以种子为标记（marker），以 `-saliency` 为地形，做分水岭分割。只有 saliency 足够高的区域才会被"淹没"纳入
- 优势：自动找到种子的自然边界（saliency 骤降处），比固定膨胀距离更精确

**c) 种子质量的主动筛选**
- 当前种子来源是 diff 阈值（14~22），包含大量噪声种子
- 改进：种子不仅要求 diff 高，还要求该位置在 7×7 邻域内 flow 方向方差低（一致性种子）。噪声通常方向混乱
- 预期收益：从源头减少噪声种子数量，间接减少扩张产生的 FP

### 10.3 场景几何先验

**a) 道路平面掩码**
- 利用外参（相机高度 0.66m）估计地面平面区域，该区域 motion 具有特定模式
- 路面 motion 方向应与相机运动方向一致（径向向外）；方向不一致的路面检测大概率是噪声

**b) 目标尺度-位置先验**
- 鱼眼图像中车辆/行人的像素面积与其距 camera 距离有关
- 靠近边缘（距离远）的目标小，靠近中心（距离近）的目标大
- 可用于 CCA 阶段的面积阈值自适应调整

### 10.4 不可行方向（已排除）

| 方向 | 排除原因 |

| 深度学习 | 用户限制，不可使用 |
| Farneback 参数调优 | 当前参数已是 OpenCV 推荐值，调整空间有限 |

## 十一、V7-V10：50帧新信号维度迭代（2026-06-07）

在 50 帧评估集上进行了一整天迭代，发现了关键规律：

**核心发现：阈值优化是零和博弈。在 saliency_ratio 维度内做任何阈值调整（z-score、百分位、局部峰值）都是在 Precision 和 Recall 之间交换，F1 从未超越 V3。真正的突破需要正交信号维度。**

### 11.2 V7：边缘差（第一个突破）

**核心洞察**：建筑 Canny 边缘在两帧之间位置不变；车辆的 Canny 边缘会移动。比较两帧的边缘位置得到一个与光流幅值正交的信号。

```
edges_prev = Canny(prev_struct)    edges_curr = Canny(curr_struct)
         ↓                                   ↓
dist_to_prev = distanceTransform(edges_prev)  dist_to_curr = distanceTransform(edges_curr)
         ↓                                   ↓
moved_edge = edges_curr & (dist_to_prev > 3px)    ← 新位置出现边缘
disappeared_edge = edges_prev & (dist_to_curr > 3px)  ← 旧位置边缘消失

edge_weight = 0.5 + 2.5·blur(moved+disappeared) - 0.4·blur(static_edges)
saliency *= edge_weight
```

**效果**：F1 +0.0011，43/50 帧领先 V3。Precision + Recall 同涨，不是零和。

### 11.3 V10：多尺度共识 + 种子方向过滤（第二个改进）

**多尺度共识**：
```
saliency_ratio 在三个尺度分别计算：
  scale 1: window=11, sigma=3
  scale 2: window=21, sigma=7
  scale 3: window=41, sigma=15

最终 = min(ratio_11, ratio_21, ratio_41)  → 只保留全尺度一致高的像素
```

**种子方向一致性过滤**：
```
7×7 邻域 flow 方向圆形方差 R = |mean(e^(i·θ))|
R < 0.5（方向散乱=噪声种子）→ 删除
```

**效果**：F1 0.0914，40/50 帧领先 V7。

### 11.4 V8/V8b 失败教训

CLAHE（局部直方图均衡化）破坏了图像域 → 固定阈值参数失效 → 帧 00013（最大 GT，416K px）F1 从 0.71 归零。**图像域增强不适用于参数固定的管道。**

### 11.5 关键结论

1. **阈值调优无用**：V4/V5/V6 在 saliency_ratio 维度内的任何操作都是 P-R 交换
2. **正交信号有用**：边缘差是第一个被验证有效的正交信号
3. **多尺度共识有用**：第二个验证有效的改进
4. **暗目标仍是痛点**：低对比度目标在所有信号维度都弱
5. **CLAHE 方向错误**：应在参数层面做亮度自适应，而非修改图像域

### 11.6 当前最优架构（V10 最终版）

```
输入 → 结构分离(bilateral,σ=50)
    → 边缘差权重 (Canny位置比较)
    → 亮度自适应阈值 (darkness→lower threshold)
    → 地面平面掩码 (外参: h=0.66m, pitch=0.6°)
    → Farneback(structure) → 法向光流约束
    → mag × diff × edge_weight
    → 多尺度 saliency_ratio (min of 11/21/41)
    → 自适应阈值 (亮度+地面) → 候选区
    → diff种子 → 种子方向过滤(R>0.5)
    → 约束膨胀 → CCA → 形态学 → 输出

4个正交信号/先验：
  1. 边缘位置差 (空间域)
  2. 多尺度共识 (尺度域)
  3. 亮度自适应 (亮度域,参数级)
  4. 地面平面掩码 (几何先验)
```

### 11.7 关键教训

1. **乘性权重在固定阈值前 = 改阈值 = 零和博弈**：V4/V5/V6/V8/V11/color 全部失败在此
2. **CLAHE 破坏参数标定**：图像域增强 + 固定阈值 = 灾难
3. **SLIC/Watershed 太粗糙**：超像素不贴合运动边界
4. **Farneback 光流场太平滑**：散度/旋度/局部方差 ≈ 0
5. **唯一有效的改进 = 真正正交的信号 或 物理/几何先验**
