# 种子扩张法（seed_expand）问题分析与改进方案

## 一、当前性能基线（2026-06-04）

### 1.1 各方法汇总（13帧，Route A 鱼眼域）

| 方法 | IoU | Precision | Recall | **F1** | TP总和 | FP总和 | FN总和 |
|------|-----|-----------|--------|--------|--------|--------|--------|
| diff (帧差) | 0.0883 | **0.1515** | 0.2305 | 0.1510 | 293K | 814K | 454K |
| flow (光流) | 0.0774 | 0.0822 | 0.7852 | 0.1236 | 615K | 6.50M | 132K |
| hybrid (混合) | 0.0648 | 0.1587 | 0.1207 | 0.1147 | 179K | 407K | 568K |
| adaptive (自适应) | 0.0618 | 0.1644 | 0.1004 | 0.1080 | 183K | 324K | 564K |
| **V1 seed_expand** | 0.0902 | 0.0939 | **0.8413** | 0.1455 | 641K | 4.89M | 106K |

### 1.2 核心矛盾

```
                    Precision            Recall
帧差法 → 高精度(0.15)        低召回(0.23)
光流法 → 低精度(0.08)        高召回(0.79)    ← FP=6.5M，几乎全是噪声
seed_expand → 低精度(0.09)   最高召回(0.84)   ← 取了光流的高召回但继承了噪声
```

**根因**：Farneback光流在鱼眼图像中产生结构性伪影——即使在静止区域，>50%像素的光流幅值也超过2.0像素/帧。这不是随机噪声（降采样无法消除），而是光流算法在鱼眼畸变下的系统性偏差。

---

## 二、改进方案及实验结果

### 方案 1：自适应百分位阈值 — V2/V3

**状态**：⚠️ 部分有效，但非银弹

**思路**：用帧差/光流的百分位值动态设定阈值，代替固定阈值。

**实验结果**：
- V2 (P95种子 + P90光流)：F1=0.1289，Precision提升(+37%)但Recall骤降(-65%)
- V3 (V2 + 方向一致性)：F1=0.1303，方向一致性仅带来+0.0014的微小提升
- **问题**：百分位阈值在极端帧上灾难性失效
  - 极小运动帧(00003)：P95仍取到噪声，种子全灭
  - 极大运动帧(00013)：P90光流过于宽松，噪声淹没信号
- **价值**：在中等运动帧上表现出色（00039: F1=0.48 vs V1的0.29）

**结论**：不作独立方案，但自适应思路融入V10的帧分类器中。

### 方案 2：光流方向一致性 — V3/V4

**状态**：⚠️ 边际改进，性价比低

**思路**：候选像素的光流方向必须与最近种子一致（角度差<45°）。

**实验结果**：
- V3 vs V2：F1仅提升 0.1289→0.1303（+0.0014）
- V4 (低种子阈值+紧扩张+方向)：F1=0.1382，不如V1
- **问题**：计算量巨大（GaussianBlur大核 + arctan2 + 角度差），收益微乎其微
- 鱼眼边缘区域光流方向本就因畸变而不稳定，方向约束容易误杀真实运动

**结论**：仅在中弱运动帧中作为辅助过滤，V10中选择性启用。

### ~~方案 5：多尺度种子扩张~~ — V8

**状态**：❌ 失败，已放弃

**思路**：在图像金字塔上分别做种子扩张，然后多数投票。

**实验结果**：
- V8: F1=**0.1358**，低于V1(0.1455)，低于V5(0.1465)
- FP反而增加（5.50M vs V1的4.89M）
- **失败原因**：光流噪声是结构性伪影，在所有尺度均存在；降采样+插值回原尺寸反而扩散了噪声边界

**结论**：放弃此方向。

### ⭐ 方案 5B：相对光流比率（ratio-based）— V5/V6/V10

**状态**：✅ **核心突破方向**

**核心洞察**：不再用"光流幅值>阈值"作为候选区，改用：
```
mag_ratio(x,y) = mag(x,y) / mean_mag(41×41邻域)
candidate = mag_ratio > ratio_thresh
```

物理含义：**该像素的运动比周围像素快多少倍**。这天然抑制了均匀背景噪声（ratio≈1.0），只保留真正"突出"的运动区域。

**实验结果**：

| 方法 | F1 | Precision | Recall | FP | 说明 |
|------|-----|-----------|--------|-----|------|
| V1 (abs flow) | 0.1455 | 0.0939 | 0.8413 | 4.89M | 基准 |
| V5 (ratio=2.0固定) | 0.1465 | **0.1397** | 0.2246 | **831K** | FP减少83%！但Recall太低 |
| V6 (abs + ratio) | 0.1302 | 0.1092 | 0.2285 | 1.10M | 不如纯ratio |
| **V10 (自适应ratio)** | **0.1542** | 0.1192 | 0.3350 | 1.31M | **F1最高！** Recall比V5+49% |

**V10的设计**（当前最优）：
1. **候选区** = flow ratio > 自适应阈值（1.3~2.2，由P95_diff决定）
2. **种子** = 低阈值(14-22)帧差 + 空间一致性过滤(V7方案)
3. **扩张** = 距离约束，expand_dist自适应(4-12)
4. **辅助** = 强运动帧加abs flow检查 + 中弱帧加方向一致性

**为什么ratio方法有效**：
- Farneback在鱼眼图像中的噪声是"整体偏高但局部均匀"——整幅图的光流幅值都大，但邻域之间差异小
- ratio消除了这个全局偏移，只关注局部异常
- FP从4.89M降至1.31M（73%↓），同时F1从0.1455升至0.1542（+6%）

### 方案 3：种子密度反馈

**状态**：⏳ 已融入V2/V10，不独立评价

5行代码的轻量改进，在种子过少时自动降低阈值重试。V2和V10内部已包含此逻辑。

### 方案 4：区域自适应参数

**状态**：⏳ 尚未独立实验

针对鱼眼中心/边缘畸变差异的参数映射。V10的帧自适应间接覆盖了部分需求（不同运动强度的帧用不同参数），但未显式建模空间畸变分布。

### 方案 6：连通域分析

**状态**：⏳ 尚未实验

用连通域分析替代固定核形态学，按区域大小自适应处理。

### V7：空间一致性种子过滤

**状态**：✅ 有效，已融入V10

用7×7窗口内的邻居种子数量过滤孤立种子。允许使用更低的seed_thresh而不引入噪声。单独使用F1=0.1301（不如V1），但作为**辅助模块**价值大——V10借此将seed_thresh从V1的45降至14-22。

### V9：帧自适应策略选择

**状态**：⚠️ 方向正确但实现粗糙

根据P95_diff将帧分为强/中/弱三类，分别使用不同策略。F1=0.1421（不如V1/V5），但思路被V10继承和精炼。

## 三、当前最优方法：V10

### 3.1 算法流程

```
1. 计算帧差diff和光流flow（各一次，复用）
2. 帧分析：P95_diff = percentile(diff, 95)
3. 自适应参数选择：
   ┌──────────────┬──────────┬──────────┬──────────┬──────────┐
   │ P95_diff     │ >120     │ 80-120   │ 55-80    │ <55      │
   ├──────────────┼──────────┼──────────┼──────────┼──────────┤
   │ seed_thresh  │ 22       │ 20       │ 18       │ 14-16    │
   │ ratio_thresh │ 1.3      │ 1.5      │ 1.6      │ 1.8-2.2  │
   │ expand_dist  │ 12       │ 10       │ 8        │ 4-6      │
   │ abs_flow     │ ✓(2.0)   │ ✓(2.5)   │ ✗        │ ✗        │
   │ direction    │ ✗        │ ✗        │ ✓        │ ✓        │
   └──────────────┴──────────┴──────────┴──────────┴──────────┘
4. 种子：diff > seed_thresh AND 局部邻居数 ≥ 3
5. 候选：flow_ratio > ratio_thresh（+ abs flow检查 if 强运动）
6. 扩张：候选像素距最近种子 ≤ expand_dist
7. 方向一致性过滤（仅中弱帧）
8. 形态学开闭
```

### 3.2 性能

| 指标 | V1 | V5 | V10 | V10 vs V1 |
|------|-----|-----|------|-----------|
| F1 | 0.1455 | 0.1465 | **0.1542** | +6.0% |
| Precision | 0.0939 | 0.1397 | 0.1192 | +26.9% |
| Recall | 0.8413 | 0.2246 | 0.3350 | -60.2% |
| FP(M) | 4.89 | 0.83 | 1.31 | -73.2% |
| TP(K) | 641 | 310 | 377 | -41.2% |

**V10在4/13帧上取得最优F1**：00002, 00006, 00007, 00041。

### 3.3 局限

- Recall从V1的0.84降至0.34——仍有大量运动区域漏检
- 强运动帧(00013)上V1仍是最优（F1=0.678 vs V10=0.572）
- 极小运动帧(00003)上所有方法都失效（F1<0.002）
- ratio_thresh的分档阈值是手工设定的，未系统调优

### ⭐ V11：区域自适应ratio + 强运动回退 + CCA后处理

**状态**：✅ 当前最优（2026-06-04）

#### 核心改进（P0+P1+P2）

**P0a — 强运动帧V1回退**：
P95_diff > 120时，完全使用V1策略（abs flow, 宽扩张）。直接解决00013上V10退化的问题：
- 00013: V11 F1=0.678（=V1），vs V10 F1=0.572

**P0b — 精炼的帧自适应参数**：
5档P95_diff分档（>100/>70/>50/>30/else），每档参数从V10经验继承并微调。

**P1 — 区域自适应ratio阈值**：
不再使用全局ratio_thresh，改为径向渐变：
```
ratio_thresh(r) = ratio_thresh_base × (1.0 + edge_bonus × (r/r_max)²)
```
- 中心区域：base阈值（畸变小，光流可靠）
- 边缘区域：base + 二次增长的bonus（畸变大，噪声多）
- `edge_bonus = 0.35`（边缘最高+35%）

**P2 — CCA小连通域去除**：
- 用cv2.connectedComponentsWithStats去除面积<50px的孤立噪声
- 再用标准形态学（7×7 open+close）闭合内部空洞
- 注：凸包填充和合并步骤经测试会过度扩张mask（15%→51%覆盖），已移除

| Precision | 0.0939 | 0.1397 | 0.1192 | 0.1190 | -0.2% |
| Recall | 0.8413 | 0.2246 | 0.3350 | 0.3290 | -1.8% |

#### 关键发现

- V11在Strong和Medium运动组最优——区域自适应ratio和V1回退在这两组发挥关键作用
- V1在Med-Strong和Weak组仍最优——低噪声环境下，高Recall的简单策略更有效
- V11的TP比V10高13.6%但FP反而降低4.2%——同时提升了检测能力和噪声抑制
- 凸包填充(CVX hull)在鱼眼mask上过度扩张——已验证并移除，仅保留CCA去噪+形态学

#### 仍未解决的问题

- 极小运动帧(00003, 00021等)所有方法失效——信号完全淹没在噪声中
- V1在某些帧上仍是最优——表明帧自适应策略可以更细化
- 时间一致性(P3)尚未实现——连续帧间的运动连续性未利用
- 参数尚未系统网格搜索调优（仅经验调整）
