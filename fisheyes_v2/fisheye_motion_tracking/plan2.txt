# 后续优化方向总结

经过 V1~V11 的实验，传统基于阈值、形态学和后处理的优化空间已经基本挖掘完成。当前 V11 已经通过 Flow Ratio、帧自适应参数、空间一致性种子过滤以及 CCA 连通域后处理等策略，在 Precision 与 Recall 之间取得了较好的平衡。后续继续微调 ratio_thresh、expand_dist、CCA 面积阈值或形态学核大小，预计只能获得有限收益。

当前系统的核心瓶颈已经不再是参数选择，而是背景与前景运动无法有效分离。鱼眼图像中的大量误检主要来源于相机运动和鱼眼畸变带来的结构性光流噪声，而非运动目标本身。因此，后续优化重点应从“参数调优”转向“背景建模与运动补偿”。

优先级最高的方向是 Route B（去畸变域处理）。具体流程为：首先利用 radial_poly 标定参数将鱼眼图像映射到透视域，在透视域内执行 V11 运动检测流程（帧差、Flow Ratio、CCA 等），最后将结果反投影回鱼眼域进行评估。由于 Farneback 光流及大部分传统运动分析算法本身是针对透视图像设计的，因此该方案有望显著降低边缘区域的伪光流和误检问题。

第二个重点方向是背景运动补偿。由于当前数据仅提供前一帧和当前帧，可考虑利用全局光流估计背景主运动方向和幅值，计算残差光流（Residual Flow）：

Residual Flow = Flow - Global Flow

其中 Global Flow 可由全图光流的中值或主方向估计得到。这样能够先消除大部分背景运动，仅保留与背景运动模式明显不同的局部目标区域，从而提高车辆和行人的分离效果。

第三个方向是充分利用鱼眼标定参数进行运动归一化。目前系统使用的是像素位移（Pixel Flow）作为运动量度，而在鱼眼图像中，相同的像素位移在中心区域和边缘区域对应完全不同的真实角度变化。因此可以利用标定模型将光流转换为视线方向（Ray）变化，进一步计算角位移（Angular Flow）：

θ = arccos(ray₁ · ray₂)

利用角位移替代像素位移进行运动检测，可以从物理意义上消除鱼眼畸变带来的空间不均匀性。

此外，还可以统计整个数据集中的径向光流分布，建立 expected_mag(r) 模型，对不同半径位置的光流进行归一化处理：

norm_mag = mag / expected_mag(r)

该方法相比当前 V11 中基于经验参数的 edge_bonus 更符合鱼眼成像规律，也更容易在实验报告中体现对鱼眼模型的利用。

综上，后续工作的优先级建议为：

1. Route B（去畸变域）+ V11 完整实验；
2. 全局背景运动估计与 Residual Flow；
3. Angular Flow（基于鱼眼标定的角位移计算）；
4. 径向统计归一化模型；
5. 时间一致性与跨帧平滑。

不建议继续投入大量时间在阈值、CCA 参数、形态学核尺寸以及扩张距离等局部调参工作上，因为相关方向已经在 V1~V11 中得到充分验证，进一步收益预计较小。
