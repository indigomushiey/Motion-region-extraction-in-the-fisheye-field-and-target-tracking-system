# 鱼眼视频中的运动区域提取与目标跟踪系统

## 一、项目背景

鱼眼相机具有超大视场角，能够覆盖传统透视相机难以观测的大范围环境，因此广泛应用于：

- 自动驾驶环视系统
- 机器人视觉感知
- 智能交通
- 全景监控
- SLAM 与导航

然而，鱼眼镜头存在明显的非线性畸变，尤其在图像边缘区域更加严重。这种畸变会导致：

- 目标形状拉伸
- 尺度变化不稳定
- 光流方向偏移
- 运动区域提取不完整
- 跟踪框漂移

因此，传统基于透视图像设计的运动分析方法在鱼眼图像中往往性能下降。

本项目围绕：

**"鱼眼图像中的运动区域提取与目标跟踪"**

展开研究，并重点分析：

**"鱼眼域直接处理" 与 "重映射后处理"**

两种技术路线之间的差异。

## 四、项目技术路线

本项目采用 **"鱼眼重映射 + 相邻帧运动分析 + 光流辅助跟踪"** 的整体技术路线。

系统支持两条处理路线：

| 路线 | 说明 |
|------|------|
| **Route A: 鱼眼域直接处理** | 在原始鱼眼图像上进行运动检测，保持原始畸变信息 |
| **Route B: 重映射后处理** | 先用 radial_poly 模型去畸变，在透视平面上检测，再反投回鱼眼域评估 |

### 处理流程

```
鱼眼当前帧 + 鱼眼前一帧
        │
        ├──→ Route A: 鱼眼域运动检测 ──→ Motion Mask (鱼眼域)
        │
        └──→ Route B: radial_poly 去畸变 ──→ 透视域运动检测 ──→ 反投回鱼眼域
                │
                ▼
           Motion Mask ──→ 轮廓检测 ──→ Kalman 跟踪 ──→ 可视化
                │
                ▼
           与 GT 对比评估 (IoU / Precision / Recall / F1)
```

## 五、运动检测方法

目前实现了 **10 种运动检测方法**：

### 5.1 基础方法

#### 5.1.1 帧差法 (diff)
```
D(x,y) = |I_t(x,y) - I_{t-1}(x,y)|
mask = D > diff_thresh
```
- **参数**: `diff_thresh=40`, `morph_ksize=5`
- **优点**: 简单快速，平均 Precision 最高(0.15)
- **缺点**: Recall 偏低(0.23)，对光照变化敏感

#### 5.1.2 光流法 (flow)
基于 Farneback 稠密光流，取幅值阈值：
```
flow = Farneback(I_{t-1}, I_t)
mag = ||flow||
mask = mag > mag_thresh
```
- **参数**: `mag_thresh=3.0`, `morph_ksize=9`
- **优点**: Recall 高(0.79)，捕获大范围运动
- **缺点**: FP 极多(6.5M)，Precision 很低(0.08)

#### 5.1.3 混合法 (hybrid)
帧差 AND 光流，取交集降低误检：
```
mask = diff_mask & flow_mask
```
- **参数**: `diff_thresh=50`, `mag_thresh=3.0`, `morph_ksize=7`
- **优点**: FP 最少
- **缺点**: Recall 损失严重(0.12)，F1 最低

#### 5.1.4 自适应阈值法 (adaptive)
基于径向距离的渐进阈值，边缘区域提高阈值并额外校验光流：
```
th_map(r) = center_thresh + (r/r_max) * (edge_thresh - center_thresh)
mask = diff > th_map  (边缘区域额外 AND flow > edge_flow_thresh)
```
- **参数**: `center_thresh=40`, `edge_thresh=80`, `edge_flow_thresh=2.0`
- **特点**: 考虑鱼眼畸变的空间分布特性

### 5.2 种子扩张系列 (seed_expand)

#### 5.2.1 V1 — 基础种子扩张（基准）
**核心思路**：帧差提供高精度种子 → 光流扩张覆盖完整运动区域 → 距离变换限制扩张范围

```
1. seed  = diff > seed_thresh              ← 高精度种子（帧差法）
2. candidate = ||flow|| > flow_thresh       ← 高召回候选（光流法）
3. dist = distanceTransform(seed == 0)      ← 到最近种子的距离
4. expanded = candidate & (dist <= expand_dist)  ← 仅保留种子附近的候选
5. mask = seed | expanded                  ← 合并种子 + 扩张区域
6. 形态学后处理 (open + close)
```
- **参数**: `seed_thresh=45`, `flow_thresh=2.0`, `expand_dist=12`, `morph_ksize=7`
- **优点**: Recall 最高(0.84)，F1=0.146
- **缺点**: Precision 很低(0.09)，FP=4.9M——继承了光流的结构性噪声

#### 5.2.2 V2/V3 — 自适应百分位阈值
- V2: 帧差P95/光流P90动态阈值 → F1=0.129
- V3: V2 + 方向一致性过滤 → F1=0.130
- **结论**：在中等运动帧(00039)上表现极好(F1=0.48)，但极端帧上灾难性失效

#### 5.2.3 V4 — 低阈值+紧扩张+方向一致性
- `seed_thresh=30`, `flow_thresh=2.5`, `expand_dist=7` + 方向一致性
- F1=0.138，不如V1

#### 5.2.4 ⭐ V5 — 相对光流比率（关键突破）
**核心洞察**：不使用绝对光流幅值，改用**相对局部均值的比率**：
```
mag_ratio(x,y) = mag(x,y) / mean_mag(41×41邻域)
candidate = mag_ratio > ratio_thresh
```
物理含义：该像素的运动比周围快多少倍。天然抑制均匀背景噪声(ratio≈1.0)。

- F1=**0.1465**，Precision=**0.14**，FP仅**831K**（比V1减少83%！）
- **这是所有后续改进的基石**

#### 5.2.5 V6 — 绝对+相对光流双重过滤
- `mag > 3.5 AND mag_ratio > 1.2`
- F1=0.130，不如纯ratio

#### 5.2.6 V7 — 空间一致性种子过滤
- 低阈值种子(20) + 7×7邻居数量过滤
- 允许更低seed_thresh而不引入噪声，作为**辅助模块**价值大
- 单独F1=0.130

#### 5.2.7 V8 — 多尺度种子扩张（方案5，已放弃）
- 图像金字塔(1.0/0.5/0.25) + 多数投票
- F1=0.136，**不如V1**。噪声在所有尺度均存在，投票反而扩散噪声
- ❌ 此方向已放弃

#### 5.2.8 V9 — 帧自适应策略选择
- 根据P95_diff选择不同策略（强/中/弱运动）
- F1=0.142，方向正确但实现粗糙

#### 5.2.9 ⭐ V10 — 自适应ratio混合（当前最优）
融合V5(ratio候选区) + V7(空间种子) + V3(选择性方向一致性) + V9(帧自适应)：
- 候选区：`flow_ratio > 自适应阈值(1.3~2.2)`
- 种子：低阈值(14-22) + 空间一致性过滤
- 扩张：距离约束(expand_dist 4-12，自适应)
- 辅助：强运动帧加abs flow检查，中弱帧加方向一致性
- **F1=0.1542，所有方法中最高！**
- FP比V1减少73%，Recall比V5提升49%

## 九、核心洞察与教训

### 9.1 什么有效 ✅

1. **flow ratio 替代绝对幅值**（V5）：不再用"像素移动了多少像素"，改用"比周围快多少"。这是最关键的突破，将FP从4.89M降至831K(-83%)。

2. **自适应参数**（V10）：不是"找一组万能参数"，而是"根据帧特征自动选择参数"。P95_diff是简单但有效的帧特征。

3. **空间一致性过滤**（V7）：不是"降低阈值=更多噪声"，而是"降低阈值+邻居过滤=更多种子+可控噪声"。

### 9.2 什么无效 ❌

1. **多尺度**（V8）：光流噪声是结构性的，所有尺度都存在，降采样+投票反而扩散噪声。

2. **方向一致性**（V3/V4）：计算量大，收益极小（F1仅+0.0014），因为鱼眼边缘的光流方向本就不可靠。

3. **绝对+相对双重过滤**（V6）：`AND` 的组合比纯ratio更差——abs flow的高阈值误杀了ratio能保留的真实运动。

### 9.3 仍未解决的问题

- **Recall-Precision tradeoff 依然尖锐**：V10获得最高F1的代价是Recall从0.84降至0.34
- **极小运动帧(00003)所有方法失效**：GT仅530px，信号完全淹没在噪声中
- **鱼眼边缘区域的畸变未显式建模**：当前所有参数全局统一
