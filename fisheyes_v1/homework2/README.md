## 图像处理与机器视觉（课程大作业）基础素材包

### 1. 作业题目
**鱼眼视频中的运动区域提取与目标跟踪算法（基于传统图像处理方法）**

本素材包用于支持本科生完成大作业的**基础版本**实验：在**鱼眼图像域直接处理**与**基于标定参数校正/重映射后处理**两条路线下，实现运动信息提取与（短时）目标/运动区域跟踪，并对比鱼眼畸变对结果的影响。



### 3. 数据来源与说明
- 数据来源：**WoodScape** 数据集（仅选取一个相机视角，优先为 **FV / Front View**）。
- 本基础包**含 包含 motion_annotations。
- 每个样本由「当前帧 + 前一帧 + 当前帧标定参数」构成，适合做**相邻帧运动分析**与**短时跟踪**。

### 4. 目录结构
```
homework2/
├─ rgb_images/          # 当前帧原始鱼眼 RGB 图像（PNG）
├─ previous_images/     # 对应“前一帧”图像（PNG）
├─ calibration_data/    # 与当前帧对应的标定参数（JSON）
└─ README.md
```

### 5. 文件命名规则（强对应关系）
- 当前帧图像：`rgb_images/{ID}_FV.png`
- 前一帧图像：`previous_images/{ID}_FV_prev.png`
- 标定参数：`calibration_data/{ID}_FV.json`

其中 `{ID}` 为 5 位数字（例如 `00000`、`00135` 等）。同一 `{ID}` 的三类文件**一一对应**。

> 注意：本基础包中的 `{ID}` 仅用于配对索引，**不同 ID 之间不保证是同一段连续视频序列**。因此：
> - 可以稳定开展“相邻两帧”的运动提取/短时跟踪实验；
> - 若要做长序列背景建模或长时跟踪，请自行设计策略或使用助教补充的连续序列（若课程后续提供）。

### 6. 标定参数文件（`calibration_data/*.json`）字段说明
每个 JSON 主要包含：
- `intrinsic`：内参及鱼眼模型参数（本数据为 `model: "radial_poly"`，多项式阶数 `poly_order=4`，并包含 `k1..k4`、图像宽高、主点偏移等）。
- `extrinsic`：外参（四元数 `quaternion` 与平移 `translation`）。**本作业通常可不使用外参**（除非你要做跨相机/世界坐标分析）。
- `name`：相机视角标识（`FV`）。

### 7. 你可以基于本数据完成的典型任务（建议流程）
你应围绕“鱼眼域直接处理”与“校正/重映射后处理”两条路线，至少完成以下大部分内容，并展示关键中间结果：

- **鱼眼图像读取与理解**
  - 读取 PNG，观察中心与边缘区域的畸变差异、尺度变化。

- **基于标定参数的鱼眼校正或重映射**
  - 根据 `intrinsic` 参数，将鱼眼图像重映射到某种目标投影（例如固定视场角的透视图、或你自定义的平面投影）。
  - 建议输出：校正前后对比图（直线结构、边缘区域变化等）。

- **相邻帧运动信息提取（传统方法）**
  - 在鱼眼域或校正域，使用两帧进行运动提取，例如：
    - 帧差 + 阈值 + 形态学清理；
    - 稳健背景建模的简化版本（两帧/少帧场景下的替代方案）；
    - 稠密/稀疏光流（如 Lucas–Kanade、Farnebäck）并生成运动幅值/方向可视化。

- **对目标/运动区域的（短时）跟踪或稳定提取**
  - 在相邻两帧间实现：运动区域连通域跟踪、基于光流的目标框传播、特征点跟踪 + 几何约束、卡尔曼滤波（两帧为最简情形，可扩展到你自行构造的短序列）。

- **对比分析**
  - 对比“鱼眼域直接处理” vs “校正后处理”在中心/边缘的差异（例如：运动掩膜的形变、目标位置漂移、特征匹配稳定性、光流一致性等）。
