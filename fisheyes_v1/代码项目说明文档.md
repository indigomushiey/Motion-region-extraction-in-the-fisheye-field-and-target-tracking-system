# 鱼眼视频运动区域提取与目标跟踪 — 代码项目说明文档

## 一、项目概览

本项目实现了鱼眼视频中的运动区域提取与目标跟踪算法，围绕两条技术路线进行对比分析：

- **路线 A**：直接在原始鱼眼图像域处理（不校正畸变）
- **路线 B**：先将鱼眼图像校正为透视/柱面/等距矩形投影，再在标准图像上处理

项目使用 Python 3.8+ 编写，核心依赖为 OpenCV（图像处理）、NumPy（数值计算）、SciPy（优化求解）、Matplotlib（可视化）和 scikit-learn（聚类）。

### 2.2 `radial_poly.py` — WoodScape 相机数学模型

**作用**：实现鱼眼镜头的数学投影模型，是**整个项目的数学基石**。没有这个文件，所有校正、光流分析、坐标转换都无法进行。

**数学模型**：

```
r(θ) = k1·θ + k2·θ³ + k3·θ⁵ + k4·θ⁷
```

其中：
- θ（theta）是入射光线与相机光轴的夹角，单位弧度
- r 是该光线落在图像传感器上的位置距离主点（图像中心）的像素数
- k1~k4 是多项式系数

**为什么不直接用 OpenCV 的 `cv2.fisheye`？**

OpenCV 的鱼眼模型公式是 `θ_d = θ(1 + k1θ² + k2θ⁴ + k3θ⁶ + k4θ⁸)`，虽然也有 4 个参数 k1~k4，但**数学含义完全不同**：
- OpenCV 的 k1 是无量纲修正系数（通常 ≈ -0.02）
- WoodScape 的 k1 是焦距像素值（= 339.749 像素）

两者**不能互换使用**，因此必须自己实现。

#### 核心函数

**`r_theta(theta, k1, k2, k3, k4)` — 正向投影**

```python
def r_theta(theta, k1, k2, k3, k4):
    t2 = theta * theta
    t4 = t2 * t2
    t6 = t4 * t2
    return k1 * theta + k2 * theta * t2 + k3 * theta * t4 + k4 * theta * t6
```

这是正向计算：给定入射角 θ → 得到像高 r。例如 θ=45°（0.785rad）→ r ≈ 264.4px。

**`theta_from_r(r, k1, k2, k3, k4)` — 反向求解（核心）**

```python
def theta_from_r(r, k1, k2, k3, k4):
    if r <= 0:
        return 0.0
    theta0 = r / k1                              # 线性初猜
    try:
        theta = newton(                          # Newton-Raphson 迭代
            lambda t: r_theta(t, ...) - r,       # f(t) = r(t) - target
            theta0,                               # 初值
            fprime=lambda t: dr_dtheta(t, ...),   # 导数
            maxiter=100, tol=1e-10
        )
    except RuntimeError:
        theta = _theta_bisect(r, ...)             # 回退到二分法
    return theta
```

这是整个去畸变流程中最关键的数学步骤。由于投影函数 `r(θ)` 是 7 次多项式，没有解析逆函数，必须用数值方法求解。

**算法流程**：
1. 初始猜测：假设线性关系 `θ₀ = r/k1`（忽略高阶项）
2. Newton 迭代：用切线逼近法迭代改进
3. 导函数 `dr/dθ` 已知（多项式求导），所以 Newton 法收敛极快（通常 3-5 步）
4. 若 Newton 不收敛（极端情况），回退到二分法（80 次二分求根）

**`validate_model()` — 模型自检**

```python
def validate_model(k1, k2, k3, k4, cx, cy):
```

|------|------|

### 2.3 `data_loader.py` — 数据加载器

**作用**：管理 WoodScape 数据集的读取、配对、序列识别。

**核心类 `DataLoader`**：

```python
class DataLoader:
    def __init__(self, data_dir, ...):
        # 扫描 rgb_images/ 获取所有有效 ID
        self.ids = self._scan_ids()      # → [0, 1, 2, 3, ..., 395]
        # 识别连续帧序列
        self.sequences = self._find_sequences()  # → [[0..27], [39..43], ...]
```

**关键设计决策 — 序列识别**：

数据集中的 130 个 ID 不是完全随机的。`_find_sequences()` 函数扫描相邻 ID，识别出 10 段连续序列（如 00000-00027 的 28 帧连续序列）。这些连续序列用于多帧背景建模和长时间目标跟踪。

```python
def _find_sequences(self, min_len=3):
    seqs = []
    cur = [self.ids[0]]
    for i in range(1, len(self.ids)):
        if self.ids[i] == self.ids[i - 1] + 1:  # 连续
            cur.append(self.ids[i])
        else:  # 断开
            if len(cur) >= min_len:
                seqs.append(list(cur))
            cur = [self.ids[i]]
    return seqs  # → 10段序列
```

**`load_pair(img_id)` — 加载单个样本**：

返回一个字典，包含：
- `curr`: 当前帧图像（1280×966 BGR）
- `prev`: 前一帧图像（1280×966 BGR）
- `gt`: 二值化运动真值（0=静止, 1=运动）
- `gt_raw`: 原始多类别真值（0, 3, 5, 6, 9 等不同类别）
- `calib`: 标定参数字典

**真值处理细节**：原始 GT 是多类别分割掩膜（像素值 0=背景, 3/5/6/9/13=不同运动目标），在 `load_pair()` 中自动二值化为 `(gt_raw > 0)`。

**`iter_sequence(seq_index)` — 连续序列迭代**：

返回真正的连续帧对 `(frame[t], frame[t+1])`，用于跟踪实验。注意这与单对帧的区别——单对帧的 `prev` 是数据集中配对的"前一帧"，而连续序列的相邻帧才是真正意义上的时间连续。

### 2.4 `undistort.py` — 去畸变/校正模块

**作用**：实现鱼眼图像到多种目标投影的校正（Route B 的核心组件）。

**支持的三种投影**：

| 投影 | 公式 | 特点 |
|------|------|------|
| **透视** (perspective) | `r_new = f · tan(θ)` | 直线保持笔直，FOV 受限（θ<90°） |
| **柱面** (cylindrical) | `x = f·φ, y = f·tan(θ_y)` | 垂直不变，水平展开 |
| **等距矩形** (equirectangular) | `x ∝ φ, y ∝ θ` | 保留全视场，但拉伸严重 |

**核心思想 — 预计算映射表**：

```python
def compute_undistort_maps_perspective_fast(k1, k2, k3, k4, cx, cy,
                                             img_w, img_h, out_w, out_h, focal):
    # ① 生成校正图像的像素坐标网格
    u_grid, v_grid = np.meshgrid(np.arange(out_w), np.arange(out_h))
    
    # ② 对每个校正图像素，反算其对应的入射角 θ
    dx = (u_grid - out_cx) / focal
    dy = (v_grid - out_cy) / focal
    r_new = np.sqrt(dx**2 + dy**2)
    theta = np.arctan(r_new)          # 透视投影反函数: θ = arctan(r/f)
    
    # ③ 通过 radial_poly 正向计算该 θ 对应的鱼眼图像坐标
    r_img = r_theta(theta, k1, k2, k3, k4)
    map_x = cx + r_img * cos_phi
    map_y = cy + r_img * sin_phi
    
    # ④ 标记超出鱼眼图像范围的无效点
    out_of_bounds = (map_x < 0) | (map_x >= img_w) | ...
    map_x[out_of_bounds] = -1  # -1 = 无效
    
    return map_x, map_y
```

映射表只计算一次（通过 `Undistorter` 类缓存），之后每帧图像只需 `cv2.remap()` 即可完成校正，处理速度极快。

**为什么预计算映射表快？**

对 900×600 的输出图像，映射表有 540,000 个像素。如果逐帧计算每个像素的 `theta_from_r()`（含 Newton 迭代），每帧需要数十秒。预计算后，`cv2.remap()` 是高度优化的 C++ 实现，单帧仅需几毫秒。

**`Undistorter` 类设计**：

```python
class Undistorter:
    def __init__(self, k1, k2, k3, k4, cx, cy, img_w, img_h):
        self._maps = {}  # 字典缓存：{(projection, out_w, out_h, focal): (map_x, map_y)}
    
    def get_maps(self, projection, out_size, focal):
        key = (projection, out_w, out_h, focal)
        if key not in self._maps:
            # 计算并缓存
            self._maps[key] = compute_xxx(...)
        return self._maps[key]
    
    def undistort(self, image, projection, out_size, focal):
        map_x, map_y = self.get_maps(...)
        undistorted = cv2.remap(image, map_x, map_y, ...)
        valid_mask = (map_x >= 0) & (map_y >= 0) & ...
        return undistorted, valid_mask
```

**`warp_mask_to_fisheye()` — 校正域→鱼眼域反向映射**：

这是 Route B 能够与 GT 进行比较的关键桥梁。GT 标注在原始鱼眼图像上，而 Route B 的运动掩膜在校正图像上。此函数利用 remap 表，将校正域掩膜"反投"回鱼眼图像坐标系：

```python
def warp_mask_to_fisheye(self, mask_undistorted, ...):
    # 遍历校正图像每个像素
    for v in range(out_h):
        for u in range(out_w):
            sx, sy = map_x[v, u], map_y[v, u]   # 查表：该校正像素来自哪个鱼眼像素
            if 0 <= sx < img_w and 0 <= sy < img_h:
                mask_fisheye[sy, sx] += mask_undistorted[v, u]
                weight[sy, sx] += 1.0
    # 归一化（多个校正像素可能映射到同一个鱼眼像素）
    mask_fisheye[valid] /= weight[valid]
```

### 2.5 `motion_extraction.py` — 运动区域提取

**作用**：实现四种运动提取算法，是项目的"算法核心"。

#### 方法一：帧差法 `frame_difference()`

```python
def frame_difference(prev_gray, curr_gray, threshold=15, blur_ksize=(5, 5)):
    prev_blur = cv2.GaussianBlur(prev_gray, blur_ksize, 0)   # 高斯去噪
    curr_blur = cv2.GaussianBlur(curr_gray, blur_ksize, 0)
    diff = cv2.absdiff(curr_blur, prev_blur)                   # |I_t - I_{t-1}|
    _, mask = cv2.threshold(diff, threshold, 255, cv2.THRESH_BINARY)
    return mask
```

**原理**：最简单直接的方法——如果某像素的灰度值在两帧之间变化超过阈值，就认为有运动。

**优点**：计算极快（仅需减法+阈值），不需要任何先验知识。
**缺点**：容易产生"双影"（运动物体的原位置和新位置都被标记），对光照变化敏感。

**三帧差分法 `three_frame_difference()`**：

```
取 diff1 = |I_t - I_{t-1}| 和 diff2 = |I_{t+1} - I_t| 的交集
→ 消除双影效应（运动物体在两帧差分中的位置不同）
```

#### 方法二：Farneback 稠密光流 `dense_optical_flow_farneback()`

这是本项目**最核心的运动提取算法**，也是最复杂的。

```python
def dense_optical_flow_farneback(prev_gray, curr_gray, params=None,
                                  compensate_ego_motion=False):
    # ① 计算稠密光流（逐像素运动矢量）
    flow = cv2.calcOpticalFlowFarneback(prev_gray, curr_gray, None, **params)
    # flow 是 (H, W, 2) 数组，每个像素有 (dx, dy) 位移
    
    mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
    
    if compensate_ego_motion:
        # ② 自运动补偿：减去中位数光流（背景主运动）
        median_flow_x = np.median(flow[..., 0])   # 所有像素X方向位移的中位数
        median_flow_y = np.median(flow[..., 1])
        residual_flow = flow.copy()
        residual_flow[..., 0] -= median_flow_x
        residual_flow[..., 1] -= median_flow_y
        residual_mag = magnitude(residual_flow)
        
        # ③ 百分位自适应阈值
        if mag_pct > 0:
            eff_th = np.percentile(residual_mag, mag_pct)  # 取P97
        else:
            eff_th = mag_th
        
        _, mask = cv2.threshold(residual_mag, eff_th, ...)
```

**自运动补偿的必要性**：

WoodScape 数据来自行驶中的汽车。相机的自身运动（ego-motion）导致**整个画面都在移动**——远处的天空移动慢，近处的路面移动快。如果不做补偿，96% 以上的像素都会被标记为"运动"。

中位数光流代表了"大多数像素的共识运动"（即背景的运动）。减去这个共识运动后，剩下的残差光流才对应对独立运动的目标（其他车辆、行人）。

**百分位自适应阈值 vs 固定阈值**：

| 方案 | 固定阈值 1.0 | P97 自适应 |
|------|:---:|:---:|
| Route A 运动像素占比 | ~70% | ~3% |
| Route B 运动像素占比 | ~96%（木桶形状！） | ~2% |
| 优点 | 简单 | 自动适配不同场景/路线 |
| 缺点 | 不适配（木桶效应） | 极端稀疏场景可能漏检 |

#### 方法三：Lucas-Kanade 稀疏光流 `sparse_optical_flow_lk()`

```python
# ① 检测特征点（Shi-Tomasi角点检测器）
prev_pts = cv2.goodFeaturesToTrack(prev_gray, maxCorners=200, ...)

# ② 金字塔 LK 光流跟踪
next_pts, status, err = cv2.calcOpticalFlowPyrLK(prev_gray, curr_gray, prev_pts, ...)

# ③ 筛选跟踪成功且位移大的点
displacements = norm(next_pts - prev_pts)
motion_points = next_pts[displacements > min_disp]
```

与稠密光流的区别：稀疏光流只跟踪几百个"可靠"的特征点（角点），而不是所有像素。速度快得多，但不适合生成完整的运动区域掩膜。

#### 方法四：背景建模 `background_subtraction_mog2()`

仅在连续帧序列上使用。`cv2.createBackgroundSubtractorMOG2()` 为每个像素维护 K 个高斯分布来建模"正常背景"，新像素与背景模型不匹配时标记为前景。

#### 统一接口 `extract_motion()`

```python
def extract_motion(prev_gray, curr_gray, method="optical_flow",
                   compensate_ego_motion=False, **kwargs):
    if method == "frame_diff":
        return {"motion_mask": frame_difference(...)}
    elif method == "optical_flow":
        return dense_optical_flow_farneback(...)
    elif method == "sparse_optical_flow":
        return sparse_optical_flow_lk(...)
```

所有上层代码（main.py）通过此接口调用，切换方法只需改一个参数。

### 2.6 `postprocessing.py` — 运动掩膜后处理

**作用**：对原始运动掩膜进行去噪、填充、筛选，输出干净的运动区域。

**标准后处理流水线 `postprocess_mask()`**：

```python
def postprocess_mask(motion_mask, ...):
    # ① 中值滤波：去除椒盐噪声（孤立的白点或黑点）
    mask = cv2.medianBlur(motion_mask, 5)
    
    # ② 开运算：先腐蚀再膨胀，去除小噪点
    kernel_open = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel_open)
    
    # ③ 闭运算：先膨胀再腐蚀，填充运动区域内部孔洞
    kernel_close = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (7, 7))
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel_close)
    
    # ④ 连通域分析 + 面积过滤
    num_labels, labels, stats, centroids = cv2.connectedComponentsWithStats(mask)
    for i in range(1, num_labels):        # 跳过 label=0（背景）
        area = stats[i, 4]                 # 连通域面积
        if area >= min_area:               # 过滤小区域
            valid_mask[labels == i] = 255  # 保留大区域
```

**形态学操作图解**：

```
原始掩膜:     ██  ████    （含噪点+孔洞）
中值滤波后:   ██  ████    （噪点减少）
开运算后:     █   ████    （孤立小点被去除）
闭运算后:     █   ████    （内部孔洞被填充）
面积过滤:         ████    （不足50px²的区域被丢弃）
```

**鱼眼域自适应后处理 `adaptive_postprocess_fisheye()`**：

这是专门为 Route A 设计的后处理：

```python
def adaptive_postprocess_fisheye(motion_mask, cx, cy, ...):
    for each connected_component:
        r_i = distance_to_center(component_centroid)
        if r_i < 0.3 * r_max:       # 中心区域（畸变小）
            min_area = 50             # 正常阈值
        elif r_i < 0.7 * r_max:     # 过渡区域
            min_area = 40             # 中等阈值
        else:                        # 边缘区域（畸变严重）
            min_area = 30             # 放宽阈值
```

**为什么边缘要用更小的面积阈值？**

鱼眼镜头的径向畸变在边缘剧烈压缩物体——同一辆汽车，在图像中心占 200 像素，在边缘可能只占 60 像素。如果全图统一用 50 px² 过滤，边缘的小运动物体就会被误删。自适应阈值让边缘区域的过滤更宽松，保留了被畸变"缩小"的运动目标。

### 2.7 `tracking.py` — 目标跟踪模块

**作用**：在多帧之间关联运动区域，实现目标持续跟踪。

#### 简化 SORT 跟踪器

**SORT**（Simple Online Realtime Tracking）的核心思想：
1. Kalman Filter 预测每个目标的下一个位置
2. 匈牙利算法将检测与预测进行最优匹配
3. 管理轨迹的创建和销毁

**`KalmanBoxTracker` 类**：

```python
class KalmanBoxTracker:
    # 状态向量（7维）：[cx, cy, area, aspect_ratio, vx, vy, v_area]
    #   cx, cy: 目标中心坐标
    #   area: 边界框面积
    #   aspect_ratio: 宽高比
    #   vx, vy, v_area: 对应速度
```

Kalman Filter 的工作流程：

```
预测阶段（predict）：
    x̂_t = F·x_{t-1}           # 状态转移矩阵预测下一帧位置
    P_t = F·P_{t-1}·F^T + Q   # 协方差传播

更新阶段（update）：
    K = P_t·H^T·(H·P_t·H^T + R)^{-1}   # 卡尔曼增益
    x_t = x̂_t + K·(z - H·x̂_t)           # 融合观测修正状态
    P_t = (I - K·H)·P_t                  # 更新协方差
```

**`hungarian_match()` — 匈牙利匹配算法**：

```python
def hungarian_match(detections, trackers, iou_threshold=0.3):
    # ① 构建代价矩阵：cost[d,t] = 1 - IoU(detection_d, tracker_t)
    cost = np.zeros((len(detections), len(trackers)))
    for d, det in enumerate(detections):
        for t, trk in enumerate(trackers):
            cost[d, t] = 1.0 - iou(det, trk.get_state())
    
    # ② 匈牙利算法求最小代价匹配
    row_ind, col_ind = linear_sum_assignment(cost)
    
    # ③ 只保留 IoU 高于阈值的匹配
    matched = [(r,c) for r,c in zip(row_ind, col_ind) if cost[r,c] < 1-iou_threshold]
```

匈牙利算法是组合优化中的经典算法，解决"如何分配使得总代价最小"的问题。`scipy.optimize.linear_sum_assignment` 是高效的 C 实现。

**`SimpleSORT` 类 — 多目标跟踪管理器**：

```python
class SimpleSORT:
    def update(self, detections):
        # ① 所有已有跟踪器预测下一帧位置
        for trk in self.trackers:
            trk.predict()
        
        # ② 匈牙利匹配
        matched, unmatched_det, unmatched_trk = hungarian_match(...)
        
        # ③ 更新匹配的跟踪器
        for d_idx, t_idx in matched:
            self.trackers[t_idx].update(detections[d_idx])
        
        # ④ 未匹配的检测 → 创建新跟踪器（可能是新出现的目标）
        for d_idx in unmatched_det:
            self.trackers.append(KalmanBoxTracker(detections[d_idx]))
        
        # ⑤ 未匹配的跟踪器丢失计数+1
        for t_idx in unmatched_trk:
            self.trackers[t_idx].misses += 1
        
        # ⑥ 删除丢失超过 max_missing 帧的跟踪器
        self.trackers = [t for t in self.trackers if t.misses <= 3]
```

**稀疏光流点跟踪 `sparse_optical_flow_tracking()`**：

对 LK 光流跟踪到的运动点使用 DBSCAN 聚类。同一目标的特征点具有相似的运动模式，DBSCAN 能自动将空间上邻近、运动一致的点聚为一类，无需预先指定目标数量。

### 2.8 `evaluation.py` — 评估指标

**作用**：定量评估算法性能，计算 IoU、Precision、Recall、F1-Score。

#### 像素级评估 `compute_metrics()`

```python
def compute_metrics(pred_mask, gt_mask):
    # 统一二值化（支持 0/1 和 0/255 两种格式）
    pred_bin = (pred_mask > 127).astype(np.uint8) if pred_mask.max() > 1 else ...
    
    # 计算混淆矩阵
    TP = sum(pred==1 & gt==1)   # 正确检测到的运动像素
    FP = sum(pred==1 & gt==0)   # 误报（静止被标为运动）
    FN = sum(pred==0 & gt==1)   # 漏检（运动被标为静止）
    TN = sum(pred==0 & gt==0)   # 正确识别的静止像素
    
    IoU = TP / (TP + FP + FN)    # 交并比
    Precision = TP / (TP + FP)   # 精确率（检测到的"运动"中有多少是真的）
    Recall = TP / (TP + FN)      # 召回率（真运动中有多少被检出）
    F1 = 2 * P * R / (P + R)    # F1分数
```

**为什么 TN 不参与核心指标？**

本场景中 TN（正确识别的静止像素）占比极高（>99%），如果把它算进指标会让所有算法看起来都很优秀（Accuracy > 99%），失去了区分度。IoU、Precision、Recall、F1 都刻意排除了 TN，聚焦于稀疏的运动像素。

#### 分区域评估 `compute_region_metrics()`

```python
def compute_region_metrics(pred_mask, gt_mask, cx, cy, ratios=[0.3, 0.7]):
    # 生成径向距离图
    r = sqrt((x - cx)^2 + (y - cy)^2)
    
    # 划分为三个区域
    center = r < 0.3 * r_max        # 中心区（畸变最小）
    transition = 0.3 <= r < 0.7     # 过渡区
    edge = r >= 0.7 * r_max         # 边缘区（畸变最大）
    
    # 在每个区域内分别计算指标
    for region in [center, transition, edge]:
        region_metrics[region] = compute_metrics(pred[region_mask], gt[region_mask])
```

这是量化"鱼眼畸变对算法性能影响"的核心工具。预期结果是：Route A 中心 > Route A 边缘（因为畸变影响）。

#### 实例级评估 `compute_instance_metrics()`

与像素级评估不同，实例级评估关心的是"检测到了几个运动目标"而不是"标记了多少运动像素"。使用匈牙利算法将预测的边界框与 GT 边界框进行最优匹配，按 IoU 阈值判断正确/错误匹配。

## 四、关键设计决策与经验教训

### 4.1 "木桶效应"的发现与修复

**问题**：Route B 的运动掩膜总是呈现桶形/椭圆形，覆盖图像的大部分区域。

**根因分析**：
1. 数据来自行驶车辆（ego-motion），全场景光流很大
2. 校正域中 Farneback 光流均值 12.9px，但阈值仅 1.0px
3. 96% 像素超标，全部标记为运动 → 透视投影的椭圆形有效区域全部变白 → 木桶形状

**修复方案**：
- 自运动补偿：中位数光流减法
- 百分位自适应阈值：`FLOW_MAG_PERCENTILE=97`
- 黑边过滤：`valid_mask` 排除投影无效区域

### 4.2 radial_poly 模型为何必须自实现

WoodScape 的投影模型 `r = k1θ + k2θ³ + k3θ⁵ + k4θ⁷` 与 OpenCV 的 `θ_d = θ(1 + k1θ² + k2θ⁴ + k3θ⁶ + k4θ⁸)` 虽然都有 4 个参数 k1~k4，但数学形式完全不同。直接套用 OpenCV 的 `cv2.fisheye` 函数会产生完全错误的校正结果。这是本项目最大的技术坑点。

### 4.3 Route A vs Route B 的结果解读

Route A（鱼眼域）IoU 始终高于 Route B（校正域），这似乎反直觉——校正后不应该更好吗？

**原因**：
1. 透视投影校正丢失了广角边缘信息（FOV 缩小）
2. `warp_mask_to_fisheye` 的反向映射引入插值误差
3. 鱼眼域的稠密光流虽然受畸变影响，但信息更完整

## 五、进一步改进方向

### 5.1 算法层面

| 方向 | 说明 | 难度 |
|------|------|:---:|
| **基于运动矢量的自运动补偿** | 当前用中位数光流减法过于粗糙。改进方案：使用 RANSAC 估计帧间单应矩阵，精确分离相机运动与独立目标运动 | 中 |
| **鱼眼域的自适应光流窗口** | Farneback 算法使用固定窗口大小。在鱼眼域中，边缘区域像素被"拉伸"，应使用更小的窗口 | 低 |
| **深度学习检测器 + 传统跟踪** | 将运动提取替换为 YOLO/Faster R-CNN 目标检测（在鱼眼域直接检测或校正后检测），然后用现有 SORT 跟踪 | 中 |
| **光流+边缘检测融合** | 光流对纹理少的区域（均匀路面）效果差，融合 Canny 边缘检测可改善 | 低 |
| **联合优化校正+检测** | 学习一个"最优校正"参数，使检测/跟踪指标最大化，而非依赖人工选择投影类型 | 高 |

### 5.2 实现层面

| 方向 | 说明 |
|------|------|
| **向量化 `warp_mask_to_fisheye`** | 当前逐像素 Python 循环极慢（每帧数秒），用 NumPy 向量化或 `cv2.remap` 反向映射可加速 100× |
| **多线程并行** | 130 帧相互独立（非连续帧对），可用 `multiprocessing` 并行处理 |
| **配置文件分离** | 将 `config.py` 中的硬编码路径改为 YAML/JSON 配置文件，支持命令行指定 |
| **增加单元测试** | 对 `radial_poly`、`evaluation` 等纯计算模块添加 `pytest` 测试 |
| **实时可视化** | 用 OpenCV `imshow` 或 Matplotlib animation 实时显示处理过程 |

### 5.3 实验层面

| 方向 | 说明 |
|------|------|
| **多参数网格搜索** | 对 `FLOW_MAG_PERCENTILE`、`MIN_CONTOUR_AREA`、`FRAME_DIFF_THRESHOLD` 做网格搜索，找最优参数组合 |
