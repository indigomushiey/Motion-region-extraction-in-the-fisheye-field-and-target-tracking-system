### 1.4 标定参数模型

```json
{
  "intrinsic": {
    "model": "radial_poly",
    "poly_order": 4,
    "k1": 339.749,    // 一阶系数（等效焦距 ≈340px）
    "k2": -31.988,    // 三阶系数
    "k3": 48.275,     // 五阶系数
    "k4": -7.201,     // 七阶系数
    "cx_offset": 3.942,
    "cy_offset": -3.093,
    "width": 1280,
    "height": 966,
    "aspect_ratio": 1.0
  }
}
```

**模型解读 — WoodScape radial_poly 投影模型**：

```
r(θ) = k1·θ + k2·θ³ + k3·θ⁵ + k4·θ⁷
```

其中：
- θ 为入射光线与光轴的夹角
- r 为图像点到主点的径向距离
- 主点坐标：`(w/2 + cx_offset, h/2 + cy_offset)` = `(643.942, 479.907)`

**与 OpenCV fisheye 模型的差异**：

| 特性 | WoodScape radial_poly | OpenCV cv2.fisheye |
|------|----------------------|---------------------|
| 投影公式 | r = k1·θ + k2·θ³ + k3·θ⁵ + k4·θ⁷ | θ_d = θ(1 + k1θ² + k2θ⁴ + k3θ⁶ + k4θ⁸) |
| 参数含义 | 直接多项式系数 | 畸变修正系数 |
| 可互换性 | **不能直接使用 cv2.fisheye 函数** | — |

**结论**：需要自行实现 radial_poly 模型的去畸变/重投影，或进行参数转换。这是本作业的核心技术难点之一。

### 1.5 真值标注分析

真值为**多类别运动分割掩膜**（非二值掩膜）：

- 像素值 0 = 静态背景
- 像素值 3, 5, 6, 9, 13 等 = 不同运动目标实例
- 运动像素占比极低（通常 <1%），典型驾驶场景特征
- 是小目标、稀疏运动场景

**评估策略**：对于二值化评估，将 `pixel > 0` 视为运动区域；对于实例级评估，按类别分离。

## 三、核心技术模块

### 3.1 radial_poly 模型去畸变（最关键的自研模块）

由于 WoodScape 使用自定义 radial_poly 模型，需要自己实现投影与反投影：

**正向投影（3D → 2D 畸变图像）**：
```
给定: 3D点 (X, Y, Z) → 归一化坐标 (x/z, y/z)
计算: θ = arctan(sqrt(x²+y²)/z) = arctan(r_3d)
      r_img = k1*θ + k2*θ³ + k3*θ⁵ + k4*θ⁷
      u = cx + r_img * (x / sqrt(x²+y²))
      v = cy + r_img * (y / sqrt(x²+y²))
```

**反向投影（2D 畸变 → 去畸变/重映射）**：
```
给定: 畸变图像坐标 (u, v)
计算: dx = u - cx, dy = v - cy
      r_img = sqrt(dx² + dy²)
      → 求解 θ = f⁻¹(r_img)（需数值求根，如 Newton 迭代）
      → 得到入射方向角 θ
      → 按目标投影模型（透视/柱面/球面）计算新坐标
```

**去畸变实现方案**：
1. **方案一（推荐）**：使用 scipy.optimize.newton 逐像素逆向求解 θ，预计算 remap 映射表，然后 `cv2.remap()` 加速
2. **方案二（简化）**：使用查表法（LUT），将 r_img → θ 的关系预先离散化计算

**目标投影类型**：
- **透视投影**（rectilinear）：`r_new = f_new * tan(θ)`，直观但有 FOV 限制（θ < 90°）
- **柱面投影**（cylindrical）：保持垂直方向不变，水平方向展开，适合全景展示
- **球面/等距投影**（equirectangular）：经纬度展开，保留全视场

### 3.2 运动区域提取

#### 方法一：帧差分法（IFD — Inter-Frame Difference）

```
diff = abs(I_t - I_{t-1})
diff_gray = cv2.cvtColor(diff, cv2.COLOR_BGR2GRAY)
_, motion_mask = cv2.threshold(diff_gray, threshold, 255, cv2.THRESH_BINARY)
```

- 最简单、最快
- 适用于相邻帧运动提取
- 缺点：对阈值敏感，易产生孔洞和双影（运动物体前后位置都被检出）

**改进**：三帧差分法
```
diff1 = abs(I_{t+1} - I_t)  # 若有三帧
diff2 = abs(I_t - I_{t-1})
motion_mask = diff1 & diff2  # 交集消除双影
```

#### 方法二：稠密光流（Farneback）

```python
flow = cv2.calcOpticalFlowFarneback(
    prev_gray, curr_gray, None,
    pyr_scale=0.5, levels=3, winsize=15,
    iterations=3, poly_n=5, poly_sigma=1.2, flags=0
)
mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
_, motion_mask = cv2.threshold(mag, mag_threshold, 255, cv2.THRESH_BINARY)
```

- 逐像素运动矢量，运动区域提取更完整
- 鱼眼域中使用会受到畸变影响（径向方向光流偏大）；校正域使用更可靠

#### 方法三：背景建模（仅适用于连续序列）

对 10 段连续序列，可使用 MOG2/KNN 建立背景模型：

```python
mog2 = cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=20, detectShadows=False)
for frame in sequence:
    fg_mask = mog2.apply(frame)
```

**注意**：由于序列较短（3-28 帧），`history` 应设得较小，且模型可能不够稳定。

#### 方法四：稀疏光流 + 区域生长（混合方案）

1. 在图像上提取 Shi-Tomasi 角点
2. 使用 Lucas-Kanade 金字塔光流跟踪
3. 筛选运动幅度大的点
4. 以这些点为中心做区域生长或 DBSCAN 聚类
5. 得到运动区域

此方法对鱼眼域、校正域都适用，且对稀疏小运动目标效果较好。

### 3.3 后处理流水线

```python
# 1. 中值滤波去椒盐噪声
mask = cv2.medianBlur(mask, 5)

# 2. 形态学操作
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)   # 去除孤立噪点
kernel_close = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (7, 7))
mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel_close)  # 填充孔洞

# 3. 连通域分析 + 面积过滤
num_labels, labels, stats, centroids = cv2.connectedComponentsWithStats(mask)
min_area = 50  # 根据实际运动目标大小调整
valid_mask = np.zeros_like(mask)
for i in range(1, num_labels):
    if stats[i, cv2.CC_STAT_AREA] >= min_area:
        valid_mask[labels == i] = 255
```

### 3.4 短时目标跟踪

由于多数数据仅为相邻帧对，跟踪策略需区分：

**单对帧（非连续 ID）**：
- 使用稀疏光流点匹配 + 运动一致性筛选
- 对运动区域连通域做双向匹配验证

**连续序列帧**：
- 构建简化版 SORT 跟踪器（Kalman Filter + 匈牙利匹配）
- 为每个检测到的运动区域分配 ID，跨帧关联

```python
# 简化 SORT 跟踪器核心逻辑
for each detection in frame_t:
    # Kalman 预测所有现有轨迹的下一帧位置
    predicted = [kf.predict() for kf in trackers]
    # 匈牙利算法匹配检测与预测
    matched, unmatched_det, unmatched_trk = hungarian_matching(detections, predicted)
    # 更新匹配的轨迹
    for d, t in matched:
        trackers[t].update(detections[d])
    # 为新检测创建新轨迹
    for d in unmatched_det:
        trackers.append(KalmanFilter(detections[d]))
    # 删除丢失的轨迹
    remove_lost_tracks()
```

### 3.5 评估指标

由于运动像素极度稀疏（<1%），需要特别注意指标计算：

```python
# 二值化 GT: 所有非零像素视为运动
gt_binary = (gt > 0).astype(np.uint8)
pred_binary = (pred > 0).astype(np.uint8)

# 逐像素指标
TP = np.sum((pred_binary == 1) & (gt_binary == 1))
FP = np.sum((pred_binary == 1) & (gt_binary == 0))
FN = np.sum((pred_binary == 0) & (gt_binary == 1))

IoU = TP / (TP + FP + FN)
Precision = TP / (TP + FP + 1e-8)
Recall = TP / (TP + FN + 1e-8)
F1 = 2 * Precision * Recall / (Precision + Recall + 1e-8)
```

**中心 vs 边缘区域划分**：
```
将图像按径向距离分为三个区域（以主点为中心）：
- 中心区: r < 0.3 * r_max（畸变最小）
- 过渡区: 0.3 * r_max <= r < 0.7 * r_max
- 边缘区: r >= 0.7 * r_max（畸变最大）
```

分别在三个区域内统计指标，量化畸变对算法性能的影响。

## 六、关键技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| radial_poly 模型实现错误 | 校正结果不对，后续全部偏差 | 用已知参数的合成图像验证正向/反向投影一致性 |
| 运动像素极度稀疏 | 评估指标对噪声极其敏感 | 后处理充分去噪；考虑使用实例级评估而非像素级 |
| 非连续帧导致背景建模失败 | MOG2/KNN 无法使用 | 仅对 10 段连续序列使用背景建模；非连续帧用帧差/光流 |
| 鱼眼域光流在边缘区域失效 | 边缘区域指标显著下降 | 鱼眼域中对特征点先 undistortPoints 再计算运动；减小 LK 窗口 |
| 不同投影方案结果不可比 | 对比分析困难 | 所有指标统一在原始鱼眼图像坐标系中计算 |
